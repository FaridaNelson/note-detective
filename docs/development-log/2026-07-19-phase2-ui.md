# Engineering Lessons

During the first implementation attempt several workflow weaknesses were discovered.

### Initial Issues

- stale working repository
- Docker mounted an outdated clone
- unnecessary Git remote access
- agent attempted Git branch management
- agent attempted global Git configuration changes

---

## Workflow Improvements

The development workflow was redesigned to:

- generate a Git Bundle from the local repository
- clone a clean working repository inside the VM
- remove all Git remotes
- mount only the clean repository into OpenClaw
- prohibit network Git operations
- prohibit commits inside the AI workspace
- transfer changes exclusively as Git patches
- perform all validation, commits, and pushes locally

The revised workflow completed the entire Phase 2 implementation successfully.
